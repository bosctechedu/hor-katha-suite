📌 Summary: Hum aapki personal files, keystrokes, ya passwords track nahi karte. Hum sirf anonymous device ID aur license information store karte hain — taaki license verify ho sake aur piracy rok sakein.

1️⃣ What We Collect

Hum ye information collect karte hain:

Data Type Purpose Storage
Device ID (anonymous fingerprint) License verification & device lock Encrypted (AES-256)
License Key Pro activation Encrypted (local + server)
Activation Timestamp Support & audit Encrypted server
Browser & OS Type Compatibility Anonymous
Crash Reports (if enabled) Bug fixing Anonymous

2️⃣ What We Do NOT Collect

❌ Hum ye kabhi collect nahi karte:
  • Aapki files ya documents
  • Keystrokes ya typing history
  • Passwords ya bank details
  • Camera ya microphone data
  • Location (GPS ya IP-based)

  • Contacts ya SMS

3️⃣ Why We Collect This Data

  • License Verification — Aapka Pro license sirf aapke device pe chale
  • Piracy Prevention — Same license multiple devices pe rokne ke liye
  • Customer Support — Agar aapko issue ho to aapka device ID se help kar sakein
  • Security Audit — Suspicious activity detect karne ke liye

4️⃣ How We Store Data

🔐 Encryption: Saara sensitive data AES-256 encryption se store hota hai. Transmission HTTPS/TLS 1.3 se hota hai.
  • Local Storage — Device pe encrypted format me
  • Server Storage — Firebase / Supabase (encrypted at rest)
  • Backup — 30 days retention, phir auto-delete
